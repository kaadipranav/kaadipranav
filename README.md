## How the projects connect

Existing systems lose important context, permit unsafe actions, or fail to support the people using them.

I tend to respond by building infrastructure:

- **WatchLLM** governs agent actions.
- **Klyd** preserves engineering decisions.
- **Codify** supports practical programming education.
- **Sanboxx** makes cybersecurity detection understandable.
